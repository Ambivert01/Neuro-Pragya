# NeuroPragya website
React 18 + Vite + Tailwind 3 + React Router (HashRouter, works on any static host).
- `npm install` then `npm run dev` (dev) / `npm run build` (output in `dist/`)
- Content: `src/data.js`. Pages: `src/pages/`. Images: `public/img/`.
- Contact form posts to FormSubmit (formsubmit.co) and delivers to CONTACT.email. First submission needs one-time activation from the inbox.
